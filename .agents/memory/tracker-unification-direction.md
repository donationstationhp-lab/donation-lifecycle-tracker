The user acknowledged the recommended direction: one authoritative backend with complementary lifecycle and exchange interfaces, using this workspace as the provisional backend foundation. Organizations is the recommended first development milestone.

**Why:** The trackers have related source history but divergent schemas and authentication. Repository similarity and empty managed-database counts do not establish the other published app's actual inventory.

**How to apply:** Separate development work from live consolidation. Before migrating or switching either live site, confirm both live datasets, reconcile identities and field meanings, explicitly map staff access, rehearse safely, and obtain authorization for the live switch. Acceptance of the outline alone is not authorization to merge databases, replace authentication, or retire a deployment.
